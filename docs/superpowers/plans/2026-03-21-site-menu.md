# SiteMenu Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a sticky black 85px nav bar with social icons that renders at the top of every page, and reposition PubDate to visually overlap the menu/cover boundary.

**Architecture:** One new component (`SiteMenu.svelte`) added to `+layout.svelte` as the first unconditional element. Cover.svelte gets a template restructure (`.pubdate-wrapper` moves up one level to escape `overflow: hidden`) and a CSS update.

**Tech Stack:** Svelte 5 (SiteMenu), Svelte 4 (Cover — no migration), vitest-browser-svelte for tests

**Spec:** `docs/superpowers/specs/2026-03-21-site-menu-design.md`

## Chunk 3: PubDate overlap

### Task 4: Reposition PubDate in Cover.svelte

**Files:**
- Modify: `src/lib/components/Cover.svelte`

**Context:** `.pubdate-wrapper` is currently inside `.cover` (line 36), which has `overflow: hidden` (line 131). Moving it to `.cover-wrapper` (line 28) lets it use `top: -25px` to protrude upward into the menu bar. `.cover-wrapper` has only `position: relative` set — no `overflow` — so absolutely-positioned children at negative offsets are not clipped.

- [ ] **Step 1: Write a failing test for the new PubDate positioning**

Create `src/lib/components/Cover.svelte.spec.js`:

```js
import { describe, expect, it } from 'vitest';
import { render } from 'vitest-browser-svelte';
import Cover from './Cover.svelte';

describe('Cover — PubDate positioning', () => {
  it('pubdate-wrapper is a direct child of cover-wrapper, not cover', async () => {
    const { container } = render(Cover, { title: 'Test', cover_img_url: '', articles: [], column: '', isHome: false });
    const coverWrapper = container.querySelector('.cover-wrapper');
    const cover = container.querySelector('.cover');
    const pubdateInWrapper = coverWrapper.querySelector(':scope > .pubdate-wrapper');
    const pubdateInCover = cover.querySelector(':scope > .pubdate-wrapper');
    expect(pubdateInWrapper).not.toBeNull();
    expect(pubdateInCover).toBeNull();
  });
});
```
