Article_Header layout

Row 1 uses flexbox with 2rem gaps — avatar + name, read time, date. On mobile, avatar+name stay together while read time and date drop to their own row. Row 2 is emoji-only, bordered top and bottom.

Architecture approach

A

In the root layout

Add Article_Header to +layout.svelte between Cover and #page. Reads from $page.data. Shown whenever author is present. No per-article changes needed.

B

Nested article layout

Add a src/routes/[year]/[month]/[slug]/+layout.svelte that wraps only article pages. Cleaner separation but requires a new file and careful slot handling.

C

Inside each article SVX

Each +page.svx imports and renders Article_Header manually. Maximum flexibility, but requires touching every article file.
